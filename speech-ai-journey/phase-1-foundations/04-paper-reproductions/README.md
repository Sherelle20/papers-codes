# 04 — Reproductions de papiers fondateurs

## Objectifs

Lire et reproduire les résultats clés de chaque papier avec du code propre et documenté.

## Papiers

### Whisper (Radford et al., 2022)
- Dossier : `whisper/`
- [arxiv](https://arxiv.org/abs/2212.04356)
- Points clés : weak supervision à grande échelle, multitâche, multilingue

### wav2vec 2.0 (Baevski et al., 2020)
- Dossier : `wav2vec2/`
- [arxiv](https://arxiv.org/abs/2006.11477)
- Points clés : self-supervised learning, quantization, fine-tuning CTC

### HuBERT (Hsu et al., 2021)
- Dossier : `hubert/`
- [arxiv](https://arxiv.org/abs/2106.07447)
- Points clés : masked prediction sur clusters, offline k-means labeling

## Format attendu pour chaque reproduction

```
papier/
├── README.md      résumé du papier + ce que j'ai reproduit
├── notes.md       mes notes de lecture
└── notebooks/     code de reproduction
```
