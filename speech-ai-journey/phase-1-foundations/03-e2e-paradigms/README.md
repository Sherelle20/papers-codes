# 03 — Paradigmes end-to-end

## Objectifs

- Comprendre et implémenter CTC (Connectionist Temporal Classification)
- Comprendre RNN-Transducer et ses avantages pour le streaming
- Comprendre Attention Encoder-Decoder (AED)

## Comparatif

| Paradigme | Streaming | Complexité | Qualité |

| CTC | ✅ Facile | Faible | Bonne |
| RNN-T | ✅ Natif | Moyenne | Très bonne |
| AED | ❌ Difficile | Élevée | Excellente |
